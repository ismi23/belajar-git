# Belajar Git Remote

Git Remote digunakan untuk mengelola koneksi antara repository lokal dan repository jarak jauh.

## Perintah Git Remote

- git remote: melihat daftar remote.
- git remote -v: melihat URL remote.
- git remote show origin: melihat informasi remote.
- git remote get-url origin: melihat URL remote.
- git remote add: menambahkan remote.
- git remote rename: mengganti nama remote.
- git remote remove: menghapus remote.

## Git Fetch dan Git Pull

- git fetch: mengambil informasi terbaru dari remote tanpa menggabungkannya ke branch lokal.
- git pull: mengambil sekaligus menggabungkan perubahan dari remote.

## Tujuan

Memahami cara mengelola remote repository dan mengetahui perbedaan Git Fetch dengan Git Pull.
