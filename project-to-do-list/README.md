# To-Do List — Project Latihan Git

Aplikasi To-Do List sederhana yang dibuat menggunakan HTML, CSS, dan JavaScript sebagai project latihan untuk mempelajari Git dan GitHub.

## Deskripsi Project

Aplikasi ini digunakan untuk mencatat dan mengelola daftar tugas sehari-hari. Pengguna dapat menambahkan tugas, menandai tugas yang sudah selesai, menghapus tugas, serta melihat jumlah tugas.

## Teknologi yang Digunakan

- HTML — Membuat struktur halaman.
- CSS — Mengatur tampilan aplikasi.
- JavaScript — Mengatur fungsi dan interaksi aplikasi.
- Git — Mengelola versi kode.
- GitHub — Menyimpan repository dan mengelola kolaborasi.

## Fitur Aplikasi

- Menambahkan tugas baru.
- Menandai tugas sebagai selesai.
- Menghapus tugas.
- Menghitung jumlah tugas.

## Cara Menjalankan Aplikasi

1. Clone repository dari GitHub.
2. Buka folder project menggunakan Visual Studio Code.
3. Masuk ke folder `project-to-do-list`.
4. Buka file `index.html` menggunakan browser.
5. Alternatifnya, gunakan ekstensi Live Server di Visual Studio Code.

## Cara Menggunakan Aplikasi

1. Buka aplikasi melalui browser.
2. Tambahkan tugas baru.
3. Tandai tugas jika sudah selesai.
4. Hapus tugas yang tidak diperlukan.

## Ide Latihan Git Berikutnya

1. Ubah warna tema pada `style.css`, lalu lakukan commit.
2. Buat branch baru untuk latihan fitur.
3. Tambahkan fitur filter tugas.
4. Buat branch untuk latihan fitur edit.
5. Latihan menggabungkan branch menggunakan merge.
6. Coba lakukan perubahan pada baris yang sama untuk mempelajari merge conflict.
