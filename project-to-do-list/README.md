# To-Do List — Project Latihan Git

Project sederhana untuk belajar Git menggunakan HTML, CSS, dan JavaScript.

## Cara menjalankan

1. Ekstrak folder project.
2. Buka folder di Visual Studio Code.
3. Buka `index.html` di browser, atau gunakan ekstensi Live Server.

## Fitur

- Menambahkan tugas.
- Menandai tugas selesai.
- Menghapus tugas.
- Menghitung jumlah tugas.

## Ide latihan Git berikutnya

1. Ubah warna tema di `style.css`, lalu commit.
2. Buat branch `fitur-filter`.
3. Tambahkan fitur filter tugas.
4. Buat branch `fitur-edit`.
5. Latihan merge kedua branch.
6. Coba buat perubahan pada baris yang sama untuk latihan merge conflict.
